# Use Case 2: Sample Code Evidence

## Task

Add server-side password reset validation to the anonymized Express sample.

**Developer comment:**

> Validate the submitted password before reset and return a safe error without leaking credentials.

## Before

Source: `myridius-auth-demo/auth/authController.js`

```javascript
exports.handleReset = (req, res) => {
  const { password } = req.body;
  // In real app: update DB with new password
  res.send('Password reset successful!');
};
```

### Before behavior

- Any request reaches the success response, including a missing password.
- The sample has no visible server-side password policy check.
- The sample does not demonstrate token validation, persistence, or error handling.

## After: AI-Generated Proposal

```javascript
exports.handleReset = (req, res) => {
  const { password } = req.body;
  if (!password || password.length < 8) {
    return res.status(400).send('Invalid password.');
  }
  // In real app: update DB with new password
  res.send('Password reset successful!');
};
```

This proposal was generated by the OpenAI path and recorded in `markdown_docs/use-case-2/evidence.md`. It is evidence of a suggested change, not an applied production change.
